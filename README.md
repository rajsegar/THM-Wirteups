## 👋 About This Repository

Welcome to my collection of TryHackMe walkthroughs and practical cybersecurity notes.

I'm an MSc Cyber Security graduate focused on developing practical skills in penetration testing, red teaming, security research, and Linux/Windows security.

This repository documents my approach to investigating vulnerabilities, exploiting authorized lab environments, troubleshooting errors, and recording technical evidence.

**My methodology:** Reconnaissance → Enumeration → Exploitation → Validation → Documentation.
